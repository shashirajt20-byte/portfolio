The Problem

Manual shipment dispatch requires coordinating warehouses, drivers, vehicles and routes. That creates unnecessary processing overhead and makes real-time tracking difficult to manage.

The Solution

SMARTLOGIX automates shipment dispatch and resource assignment, uses Dijkstra's shortest-path algorithm for route optimization, and streams live shipment updates through WebSocket endpoints.

Shipment→Dispatch Engine→Warehouse / Driver / Vehicle→Route Optimization→ETA→WebSocket Tracking

Key Engineering Features

Automated Dispatch

Automates driver and warehouse assignments.

Dijkstra Routing

Uses Dijkstra's shortest-path algorithm with O((V+E)log V) time complexity.

Real-Time Updates

WebSocket endpoints stream GPS telemetry and live shipment updates.

Security

Spring Security protects backend services.

Architecture

The backend orchestrates shipment operations: assignment logic determines resources, the route engine computes an optimal path, ETA information is produced, and WebSocket endpoints make live shipment information available to the frontend.

Implementation

Shipment request → assignment → shortest path → ETA → persistent state → WebSocket update

A logistics engine built around automation, routing and live tracking.
