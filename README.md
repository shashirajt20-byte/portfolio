# Shashi Raj Portfolio

Built from the existing portfolio content, with:
- Same homepage project content
- About section exactly as requested
- A single `200+ DSA Problems Solved` metric (no DSA topic breakdown)
- Clickable project cards
- Dedicated project pages for Offline UPI, SMARTLOGIX, and LogStream
- Project-page structure inspired by the reference project page
- Responsive dark/purple design

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project images

The homepage keeps the original `/images/upi-project.png`, `/images/smartlogix-project.png`,
and `/images/logstream-project.png` paths. If those files are not present, the cards automatically
fall back to included SVG placeholders.

Replace the placeholders with your own screenshots when ready.
