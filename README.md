# Shashi Raj Portfolio


## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Project images

The homepage keeps the original `/images/upi-project.png`, `/images/smartlogix-project.png`,
and `/images/logstream-project.png` paths. If those files are not present, the cards automatically
fall back to included SVG placeholders.

Replace the placeholders with your own screenshots when ready.
